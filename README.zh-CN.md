## 当前状态

这是可运行的开发版本，并非已发布的真实社群地图。现有功能包括双语目录、网址筛选与选择状态、聚合地理地图与公民合作连线、可选设备定位、组织与机构资料、关系证据列表、成立年份／范围／公开机构联系信息、JSON/CSV 导出，以及静态投稿和问卷草稿。私人回答不会进入公开提案。验证记录与发布条件见 [verification.md](docs/verification.md)。

正式审核数据集目前为空。演示条目都是明确标注的虚构测试数据，保存在测试夹具中，不进入正式条目目录。演示构建不可作为已核实数据发布。私密报告联系渠道目前是无法投递的开发占位符。

## 本地运行

需要 Node 24.x 和 npm 11.x。依赖版本固定在 `package-lock.json` 中。

```sh
npm ci
npm run dev:demo
```

访问 [中文地图](http://127.0.0.1:3000/zh-CN/) 或 [English atlas](http://127.0.0.1:3000/en/)。Windows PowerShell 若阻止 npm 的脚本包装器，请使用 `npm.cmd`，无需修改系统执行策略。请确保 Node 已加入 PATH；本机专用设置笔记不进入公开仓库。

`npm run dev` 只使用正式审核条目；`npm run build:demo` 创建带标注的虚构数据预览；`npm run build` 重建正式数据并清理旧页面；`npm run serve` 在 `http://127.0.0.1:4173` 提供静态预览。

## 验证与贡献

依次运行数据验证、类型检查、lint、格式检查、单元测试、静态构建和浏览器测试；完整命令见英文 README。浏览器测试使用明确的演示构建，并模拟外部请求，不能访问真实地图或组织服务。

添加组织或关系前，请阅读产品标准，提供公开组织来源和原创摘要。不要提交精确场所、个人联系方式、私密邀请、成员或参与记录、保密访谈及敏感连接。建议不等于自动公开发布。

GitHub Issue、Pull Request 和 Git 历史是公开的。不要通过这些渠道发送敏感移除报告。真实私密联系渠道尚未配置，开发占位符无法接收报告。正式条目需要人工证据及安全审核。

## 开放许可与发布

代码和原创界面素材采用 MIT；原创整理数据拟采用 CC BY 4.0，真实数据发布前需确认许可与来源兼容性。第三方来源、参考坐标和地图服务的条款及署名要求独立适用。当前没有已发布的真实组织数据集。

公开网站仍需通过审核数据、真实报告与投稿渠道、许可/来源审查及质量验证。技术文档规定了保留敏感移除的安全回滚流程。
